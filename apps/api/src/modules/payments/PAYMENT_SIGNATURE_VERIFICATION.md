# Razorpay Payment Signature Verification

## Why verification fails

The signature must be generated exactly like Razorpay expects:
- Use the same `RAZORPAY_KEY_SECRET` that the Razorpay client is configured with
- Hash `razorpay_order_id + "|" + razorpay_payment_id`
- Use HMAC SHA256
- Compare the generated signature against `razorpay_signature`

Common causes of failure:
- `RAZORPAY_KEY_SECRET` is not set or is different from the secret used in Razorpay dashboard
- Your backend receives the wrong payment identifiers
- You compare `razorpay_signature` against the wrong payload string
- You search the payment record by the wrong ID field

## What was fixed

1. `src/utils/payment/rzr.ts`
   - Razorpay client now reads `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` from `process.env`

2. `src/modules/payments/payments.schema.ts`
   - Removed `amount` from the verify payload schema, because signature verification requires only:
     - `razorpay_payment_id`
     - `razorpay_order_id`
     - `razorpay_signature`

3. `src/modules/payments/payments.service.ts`
   - Signature is now generated by `crypto.createHmac("sha256", RAZORPAY_KEY_SECRET)`
   - Uses exactly: `razorpay_order_id + "|" + razorpay_payment_id`
   - Compares using `crypto.timingSafeEqual(...)` for security
   - Looks up the payment record by `transactionId` when the payload contains the Razorpay order ID
   - Fixes the returned payment object so it returns the updated payment record

4. `src/modules/payments/payments.controller.ts`
   - Removed incorrect `await req.body` usage and uses `req.body` directly

## Environment setup

Make sure you set these environment variables when running the server:

```bash
export RAZORPAY_KEY_ID=your_razorpay_key_id
export RAZORPAY_KEY_SECRET=your_razorpay_key_secret
```

If you use a `.env` loader in your project, load those values before the app starts.

## Request payload expected by `/api/payments/verify`

```json
{
  "razorpay_payment_id": "pay_XXXXXXXXXXXX",
  "razorpay_order_id": "order_XXXXXXXXXXXX",
  "razorpay_signature": "generated_signature_value"
}
```

## How to debug

1. Confirm your request body exactly matches the field names above.
2. Confirm the `RAZORPAY_KEY_SECRET` in your app matches the Razorpay dashboard secret.
3. Confirm the `razorpay_order_id` is the Razorpay order ID, not your local app order ID.
4. Check server logs for `Invalid payment signature` or `Payment not found`.

## What to change if you still see failure

- If the signature is invalid, the secret is wrong or the payload fields are wrong.
- If the payment is not found, the webhook or verify flow is using the wrong ID field.

## Expected flow

1. Create a Razorpay order and save its ID in `payment.transactionId`
2. Client completes payment with Razorpay and sends `razorpay_payment_id`, `razorpay_order_id`, and `razorpay_signature`
3. Backend verifies the signature and updates payment status
